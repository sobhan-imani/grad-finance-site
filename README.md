# دخل و خرج جشن فارغ‌التحصیلی — راه‌اندازی رایگان

این پوشه یک سایت ثابت است (HTML + جاوااسکریپت). داده‌ها، فاکتورها و ورود کاربران روی **Supabase** (پلن رایگان) نگه‌داری می‌شوند و خود سایت را می‌شود رایگان روی **GitHub Pages** یا **Netlify** گذاشت. کتابخانه‌ها و فونت‌ها داخل پوشه هستند و سایت به CDN بیرونی وابسته نیست.

```
index.html      صفحه‌ی اصلی
config.js       آدرس و کلید Supabase (فقط همین فایل را ویرایش کن)
schema.sql      ساختار دیتابیس، دسترسی‌ها و فضای فاکتورها
vendor/         supabase-js و SheetJS (برای خروجی اکسل)
fonts/          وزیرمتن و لاله‌زار
```

## ۱) ساختن پروژه در Supabase

1. در supabase.com ثبت‌نام کن و **New project** بزن. رمز دیتابیس را جایی نگه دار. منطقه‌ی نزدیک (مثلاً Frankfurt) را انتخاب کن.
2. از منوی چپ به **SQL Editor** برو، محتوای `schema.sql` را کامل بچسبان.
3. **قبل از اجرا** در بخش ۱ فایل، دو ایمیل نمونه را با ایمیل خودت و دوستت عوض کن. فقط همین ایمیل‌ها به داده‌ها دسترسی خواهند داشت.
4. **Run** را بزن. باید پیام موفقیت ببینی.

بعداً اگر خواستی نفر سومی اضافه کنی:
```sql
insert into public.members (email) values ('someone@example.com');
```

## ۲) ساختن حساب‌ها و بستن ثبت‌نام عمومی

1. **Authentication → Users → Add user → Create new user**: برای خودت و دوستت با همان ایمیل‌ها یک رمز بساز و گزینه‌ی **Auto Confirm User** را روشن کن.
2. **Authentication → Sign In / Providers**: گزینه‌ی **Allow new users to sign up** را خاموش کن تا کس دیگری نتواند حساب بسازد. (حتی اگر بسازد هم چون ایمیلش در جدول `members` نیست، به هیچ داده‌ای دسترسی ندارد.)

## ۳) گذاشتن آدرس و کلید در `config.js`

از **Project Settings → API** (یا **Data API / API Keys**) این دو را بردار:

- **Project URL** مثل `https://abcd1234.supabase.co`
- کلید **anon** (یا **publishable**)

و در `config.js` جایگزین کن. این کلید عمومی است و قرار دادنش در سایت امن است؛ دسترسی را قوانین RLS در `schema.sql` کنترل می‌کنند. **هیچ‌وقت کلید `service_role` یا `secret` را این‌جا نگذار.**

## ۴) بالا آوردن سایت (رایگان)

**راه الف: GitHub Pages**
1. در github.com یک مخزن جدید بساز (می‌تواند Private نباشد؛ داده‌ها در Supabase هستند نه در مخزن).
2. همه‌ی فایل‌ها و پوشه‌های این پوشه را آپلود کن (Add file → Upload files).
3. **Settings → Pages → Source: Deploy from a branch → main / root** و ذخیره.
4. بعد از یکی دو دقیقه سایت روی `https://نام‌کاربری.github.io/نام-مخزن/` بالا می‌آید.

**راه ب: Netlify Drop**
به app.netlify.com/drop برو و کل پوشه را بکش و رها کن. یک آدرس `something.netlify.app` می‌گیری. (برای ماندگاری سایت، با یک حساب رایگان وارد شو.)

دامنه‌ی اختصاصی (مثل `party.example.ir`) هم در هر دو سرویس قابل اتصال است، ولی خود دامنه را باید جداگانه بخری؛ آدرس‌های `github.io` و `netlify.app` رایگان‌اند.

## ۵) استفاده

- آدرس سایت را به دوستت بده؛ هر کدام با ایمیل و رمز خودتان وارد می‌شوید.
- هر تغییری که یکی بدهد، برای دیگری **همان لحظه** نمایش داده می‌شود و روی هر ردیف نوشته می‌شود آخرین بار چه کسی تغییرش داده.
- **اتصال فاکتور به خرج**: هر فاکتور ستون `item_id` دارد که به جدول `items` اشاره می‌کند (یک خرج می‌تواند چند فاکتور داشته باشد). اتصال را از سه جا می‌شود داد:
  - موقع آپلود، در پنجره‌ی فاکتور؛
  - از منوی کشویی روی کارت هر فاکتور در تب «فاکتورها»؛
  - از داخل پنجره‌ی خود خرج («آپلود فاکتور برای این خرج» یا «وصل کردن یکی از فاکتورهای وصل‌نشده»).
- اگر خرجی حذف شود، فاکتورهایش حذف نمی‌شوند و به بخش «وصل‌نشده» برمی‌گردند.
- فایل‌ها خصوصی‌اند و فقط با لینک موقت (یک‌ساعته) به اعضای مجاز نشان داده می‌شوند. عکس‌های بزرگ قبل از آپلود کوچک می‌شوند؛ سقف هر فایل ۱۰ مگابایت است.

## نکته‌های پلن رایگان

- پروژه‌ی رایگان Supabase اگر حدود یک هفته هیچ استفاده‌ای نشود **متوقف (Pause)** می‌شود. داده‌ها پاک نمی‌شوند؛ کافی است وارد داشبورد شوی و **Restore** بزنی.
- سقف‌ها برای این کار بیش از کافی است (حدود ۵۰۰ مگابایت دیتابیس و ۱ گیگابایت فایل).
- برای پشتیبان، هر از گاهی «خروجی اکسل» بگیر.
- اگر از شبکه‌ی داخل ایران بعضی از این سرویس‌ها باز نشدند، مشکل از دسترسی شبکه است نه از سایت.
